## 🛑 第一部分：用户服务协议 (Terms of Service)

### 1. 服务内容
1.1 本产品利用先进的 AI 语音合成技术（TTS），为用户提供将文字转换为语音的服务。  
1.2 本产品分为“免费额度”和“充值加油包”两种模式：
* **免费额度**：系统自动赠送每位游客300字的免费合成额度（单次合成上限 300 字）。登陆用户1500字符。
* **付费加油包**：用户可通过购买特定的字数套餐来增加可用额度，付费额度永久有效，无单次合成限制，并可解锁高级音色。

## 🔒 第二部分：隐私政策 (Privacy Policy)

我们极其重视您的隐私，本产品采用极简的数据留存机制，最大程度保护您的信息安全：

### 1. 数据收集与存储
1.1 **文本内容**：您在输入框中输入的文本，仅用于调用底层 AI 模型生成音频。  
1.2 **缓存机制**：为了帮您节省额度，系统会临时对 `(文本+音色+情绪)` 生成的 MD5 哈希值及对应生成的音频文件进行加密存储（基于 Vercel KV 缓存）。该缓存仅用于您在短时间内重复试听或下载，我们不会对您的原始文本进行人工查看或商业化利用。  
1.3 **身份识别**：由于本产品一期采用免登录机制，系统会收集您的浏览器唯一标识（Browser Fingerprint）作为您的用户 ID，用于记录您的剩余额度及充值订单。

### 2. 数据安全保障
2.1 我们的数据托管于行业领先的云服务商（Vercel 及 火山引擎），采用标准的加密传输协议（HTTPS）。  
2.2 我们绝不会向任何第三方公司出售、共享或披露您的任何合成记录。
